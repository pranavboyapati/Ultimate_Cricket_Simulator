## Overview

Ultimate Cricket Simulator puts you in the heat of the moment — bat and score runs under pressure! Developed with Unity and C#, the game simulates critical match scenarios and lets you choose your favorite team to conquer the crease.

## Installation & Setup

Clone and open the Unity project:

```bash
git clone https://github.com/pranavboyapati/Ultimate_Cricket_Simulator.git
cd Ultimate_Cricket_Simulator
```
Then, open the project using any version of the Unity Editor released after 2021.
